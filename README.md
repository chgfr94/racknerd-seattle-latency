## RackNerd 西雅图机房实测表现怎么样

数据背后的规律很清晰：西雅图机房的联通方向上限很高，上海联通能跑出平均 645Mbps、峰值 860Mbps 的成绩，河北移动也不差。但电信方向整体崩了，多个节点只有个位数 Mbps，广西电信甚至掉到几百 Kbps。还有一点容易被忽略——联通内部也不是铁板一块，广东联通和河北联通同样测出了几百 Kbps 的结果，所以「联通友好」指的是部分节点，你的具体线路必须自己验证。

至于机器本身，这台西雅图套餐的磁盘 4K 随机读写约 84 MB/s，顺序读写超过 1.3GB/s，Geekbench 5 单核 478 分，对一个年付不到 $20 的套餐来说性能不算短板。国际方向也值得一提：到东京延迟 82.71ms、香港 127.8ms，iPerf3 单线程能跑到 700Mbps 上下，如果你拿它做面向亚太的国际业务中转，这个底子够用。流媒体就不指望了，实测 Disney+ 不解锁，IPv6 也没有。

## 西雅图、洛杉矶 DC-02、圣何塞怎么选

三个机房都在美国西海岸，但定位不同，选错机房是 RackNerd 用户最常见的不满来源。

洛杉矶 DC-02 是官方反复强调的「最受欢迎」机房，接入了亚洲优化网络，电信走 163 优化、联通走 AS4837，三网基本直连，电信延迟约 150ms、联通约 140ms，晚高峰联通方向能跑 300Mbps 以上。代价是常年缺货，且只对 2GB 及以上套餐开放。

圣何塞是 DC-02 缺货时的主力备选，电信去程直连延迟约 160ms，联通走 AS4837 表现稳定，对电信和移动用户相对友好，各档位库存也充足。

西雅图的坐标在西海岸偏北，社区评测普遍的结论是：对联通用户相对友好，整体延迟比圣何塞略高一点，但比东海岸好太多。结合前文的实测数据，它的适用人群其实很明确——联通用户想避开 DC-02 的抢购大战、或者需要美西非洛杉矶节点的（比如分流部署、做备用节点），西雅图是合理选择；电信和移动用户除非实测过自己的线路没问题，否则优先圣何塞。

## 下单前，花五分钟测一下你自己的线路

RackNerd 为西雅图机房提供了官方 Looking Glass 测试工具，支持 ping、traceroute 和 MTR，不需要注册账号。西雅图节点的测试 IPv4 是 **192.3.253.2**，还提供 10MB / 100MB / 1GB 三档下载测试文件。

正确的用法是在你常用的网络环境下，对着这个 IP 在晚高峰 20:00–23:00 测一轮：先 ping 看延迟，再 traceroute 看有没有绕路，最后拉一次测速文件看实际速度。前文那张三网测速表已经证明，同一个机房里不同运营商、甚至同运营商不同省份的节点表现能差出一千倍，别人的测速数据只能当参考，你自己的线路才是最终答案。
